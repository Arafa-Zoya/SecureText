AES-256-GCM
Symmetric, authenticated encryption. The key is derived from your password with PBKDF2-HMAC-SHA256 (600,000 iterations) and a random salt. GCM detects tampering, so a wrong password or altered data fails to decrypt. Security depends on password strength.

      
RSA-2048
Asymmetric encryption: anyone can encrypt with the public key, only the private key holder can decrypt. Here the private key is stored as encrypted PKCS8 and needs its password. RSA handles small payloads; files need a hybrid approach.

      
Caesar and Vigenère
Historical ciphers included for teaching. Caesar has only 25 useful shifts. Vigenère resists simple frequency analysis but falls to the Kasiski test. Do not use either to protect real data.

      
Good practice
Use passwords of 12+ characters, back up your private key and its password separately, and never share the private key. Lost passwords cannot be recovered because the server stores nothing.
